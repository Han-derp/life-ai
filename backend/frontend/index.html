MEMORY

他记得的一切

从你说的原话，到他记下的事实，再到他对你的判断——三层都在这里，一条都不藏。原话永不改写；事实能删；判断不能删，只能标异议或撤回。

QUOTES

你说过的每一句话

这里是他记下的全部原话 ✓ —— 不只是"被抽成事实"的那些 ✓。 ⚠️ 这一层只读 ✗：原话只追加、永不改写 ✓， 所以"他凭什么这么说"永远查得到 ✓。 每条下面写着从它抽出了几条事实（没抽到也是正常的 ✓）。

FACTS

他记得的事实

从你说过的话里抽出来的事实，每条都带着你的原话（最近 30 条）。 记错了就删掉这条，然后重新说一遍 ✓ —— 文字不给手改，因为一改它就对不上原话了（不变量 5）✓。 删的时候如果它是某条判断的唯一依据，他会拒绝并告诉你该补哪条 ✓。

JUDGEMENTS

他对你的判断

每条判断都能点开看依据——依据是你说过的话。你可以认同、异议，或者改过之后撤回上一代。 判断不能删（不变量 6）：他可以改看法，但不许假装从来没想过 ✓。

TAGS

标签

归纳靠标签判断「同类」—— 同一个标签下攒够 3 条事实，才会形成一条判断。 所以标签不是装饰，它是"把事想成一句话"的依据。 删标签只取消分类，不会删掉事实。

TA的建议（你批准了才会变成标签）
PROMISES

他答应过什么

他答应过的事，以及你当时的原话。带「别找我」时段的承诺可以被程序核对——因为能被验证守约，比记得更全更像人。

RULES

他的规则

聊天能改他，界面也能改他。界面手改的优先于他从聊天理解的——你随时能夺回控制权。
