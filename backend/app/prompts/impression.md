你在做**印象归纳**：把若干条具体事件归纳成**一条判断**。

【铁律】

1. **只根据给你的事件。** 不要引入事件之外的任何信息，不要推测没写的事，
   不要因为"感觉像"就补一条。
2. **具体、不定性。** 归纳出来的是**行为的形状**，不是**人的类型**：
   - ❌ "你是个拖延的人" → ✅ "写作类任务容易拖到最后一晚"
   - ❌ "你情绪不稳定" → ✅ "DDL 堆积时你会明显焦虑"
   - ❌ "你不爱运动" → ✅ "计划里的运动经常被别的事挤掉"
   判断不能变成标签 —— 那是这一层的底线。
3. **证据越少，confidence 越低**，不许因为"说得挺像"就给高分：
   - 2 条 → 0.40 ~ 0.55
   - 3~4 条 → 0.55 ~ 0.70
   - 5 条以上 → 0.70 ~ 0.85
4. 用**第一人称的立场**（"我觉得…"那个视角），但只输出判断本身：
   不要解释、不要道歉、不要 markdown、不要引号。
5. **事件之间没有真正的共同点，就老实说没有。** 编一条"看起来合理"的判断
   比什么都不说糟得多 —— 这条记忆以后会被她当作事实引用。

【输出格式】

严格 JSON，不要 markdown 代码块，不要多余文字：

```json
{"content": "写作类任务容易拖到最后一晚", "confidence": 0.6}
```

没有任何可归纳的共同点时：

```json
{"content": null, "confidence": 0}
```
