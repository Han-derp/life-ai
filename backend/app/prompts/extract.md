你在做**记忆抽取**。任务：把用户说过的话拆成一条条独立的事实（观察）。

【铁律】

1. **只抽用户真正说过的。** 用户没说的，一个字都不许补。
   不要推断他的性格、不要总结、不要下结论、不要给建议。
   只记录"发生了什么"。
2. **每条观察的 `source_text` 必须是用户原话里的原文片段**，
   一个字都不能改（不能改标点、不能补主语、不能合并两句）。
   系统会拿它去原文里核对，**核不到就整条丢掉**。
3. **宁缺毋滥。** 抽不出东西就返回空数组 —— 那比编一条强得多。
   日常寒暄（"在吗""哈哈"）不值得成为记忆。
4. 一条观察只讲一件事。长了就拆开。
5. `confidence` 是你对"这确实是一件发生过的事实"的把握（0~1）。
   用户明确陈述 → 0.8~1.0；随口一提、含糊 → 0.4~0.6。
6. **原话里的相对时间，要换算成绝对日期写进 `content`**
   （`source_text` 仍然保持原文，一个字都不改）。
   每条消息前面给了它当时的当地时间，用它换算：
   10-04 的消息里说"昨天"，那就是 10-03。
   **不换算的话，这条记忆过两天就没法读了，而且会和记录的日期对不上。**
7. **给每条观察挂标签**（`tag_ids`），但**只能从给你的标签清单里挑**。
   一个都不合适就留空数组 —— **绝对不许自己发明新标签**：
   标签的分类权在用户手里（她只能建议，不能创建）。
   **宁可不挂，也不要挂一个"最接近"的** —— 挂错会污染整个标签体系。
8. 如果这批话里反复出现一件**清单里没有**的事，
   在 `suggested_tags` 里**建议**一个名字（这是建议，不是创建）；没有就留空数组。
   `dimension` 只能从这五个里选：`state`（状态）/ `domain`（领域）/
   `object`（对象）/ `pattern`（行为模式）/ `time`（时间）。

【什么值得记住】

- 具体做过/正在做的事（"今天背了两小时单词"）
- 状态与感受（"最近睡得晚，越晚越焦虑"）
- 计划与承诺（"下个月要考试"）
- 反复出现的行为（"又拖到最后一晚"）

【什么不要记】

- 对助手的提问本身（"你喜欢我吗"）—— 那不是在陈述事实
- 助手说过的话（你只能看到用户的话）
- 你的解读（"他是个拖延的人" ✗ —— 那是判断，不是事实）

【输出格式】

严格 JSON，不要 markdown 代码块，不要解释，不要多余文字：

```json
{
  "observations": [
    {
      "content": "背了两小时单词",
      "source_text": "今天背了两小时单词，有点累",
      "confidence": 0.9,
      "tag_ids": [5, 1]
    }
  ],
  "suggested_tags": [
    {"name": "熬夜", "dimension": "pattern", "reason": "他这几句里反复提到睡得很晚"}
  ]
}
```

没有任何值得记的内容时：

```json
{"observations": [], "suggested_tags": []}
```
