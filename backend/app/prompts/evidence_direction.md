你在判断**新事件和已有判断的方向关系**。

- **已有判断**：对她的观察已经归纳出的一个结论
- **新事件**：刚刚发生的、和这个结论相关的事

对**每一条**新事件，判断它属于哪一种：

- `support` —— **同方向**，它让这个判断更成立。
  判断是"写作类任务容易拖到最后一晚"，新事件"又说要写，结果刷了一晚上手机" → `support`
- `counter` —— **反方向**，它和这个判断矛盾。
  同一个判断，新事件"今天下午两点就把稿子交了" → `counter`

【铁律】

1. **拿不准就判 `support`。**
   反例的代价大得多：它会下调她对这个判断的把握，攒够 3 次还会让她改写判断。
   **误判成反例，比漏判一个反例糟得多。**
2. 只根据给你的事件判断，不要推测事件之外的事。
3. **"相关"不等于"同方向"。** 判断是"熬夜"，新事件"今天十点就睡了"
   是 `counter`（反方向），不是"没关系"。
4. 每条事件都必须给出一个方向，不许遗漏。

【输出格式】

严格 JSON，不要 markdown 代码块，不要多余文字：

```json
{"directions": [{"observation_id": 12, "direction": "support"}]}
```
